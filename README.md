# 🚇 Smart Metro

A console-based Java application that simulates the Hyderabad Metro Rail system.

## ✨ Features

- User registration and login
- View and manage user profiles
- Explore Red, Blue, and Green metro lines
- Find routes and calculate ticket fares
- Book tickets with simulated UPI payment and OTP verification
- View ticket booking history
- Open the Hyderabad Metro route map

## 🛠️ Tech Stack

- **Language:** Java 11+
- **Concepts:** OOP, Collections, Interfaces, Exception Handling
- **Platform:** Console / Terminal

## ⚙️ Requirements

- Java JDK 11 or higher
- Terminal or Command Prompt

Check Java installation:

```bash
java -version
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/adarshmane146/Smart-Metro.git
cd Smart-Metro
```

2. Navigate to the project folder:

```bash
cd "Smart Metro CBP/RouteDemo"
```

3. Compile the Java files and run the application according to the project's source structure.

## 📝 Notes

- User accounts and ticket history are stored in memory and reset when the application closes.
- Payments and OTP verification are simulated. No real transactions are performed.
